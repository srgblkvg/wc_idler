# Проверка первого игрового среза

Проверено 7 октября 2026 года на Node.js 24, PostgreSQL 17 и Chromium.

- `npm run typecheck`: успешно.
- `npm test` с отдельной `TEST_DATABASE_URL`: 45 тестов, все пройдены; интеграционные тесты не пропущены.
- `npm run build`: успешно; production JavaScript около 261 КБ, gzip около 82 КБ.
- `npm audit`: 0 известных уязвимостей на момент проверки.
- Docker-образы API и браузерного клиента: успешно собраны. API запускался от UID 1000; использовал ограниченную роль PostgreSQL. Сессия и чтение персонажа работали; попытка создать таблицу от роли приложения отклонена PostgreSQL.
- HTTPS-конфигурация Caddy: валидна. Публичный домен, получение боевого сертификата и внешнее развёртывание не проверялись.

Автоматические тесты покрывают владение предметами, выдачу наград один раз, порядок боя и лечение, ограничения уровня, офлайн-лимит, частоту опроса и детерминированность симуляции. На настоящем PostgreSQL проверены изоляция игроков, хранение хешей токенов, CSRF, поддельные команды, истечение сессии, конкурирующие запросы, квитанции идемпотентности и отсутствие внутреннего RNG в ответах.

В Chromium пройден путь: создание паладина → принятие задания → охота → офлайн-догон через сервер и БД → выдача награды → экипировка молота → перезагрузка. Персонаж, завершённый квест и экипировка сохранились. Проверка второго независимого браузерного контекста подтвердила отдельный прогресс. Не было ошибок JavaScript; на ширине 390 px не было горизонтального переполнения.

Гостевой вход, отсутствие восстановления аккаунта и пределы первого среза описаны в README. Нагрузочное тестирование и долговременная эксплуатация не выполнены.

Предпросмотр `npm run preview` проверен отдельно: собранный интерфейс и API на одном порту 4173, создание персонажа, задание, охота и перезагрузка работают. Тесты статической раздачи подтвердили сохранение проверки сессии API и запрет доступа к скрытым файлам.
